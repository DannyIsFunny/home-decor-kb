## 第一章：家具设计概论

### 1.1 家具的定义

家具是指人类日常生活中供人们坐、卧、躺、凭、贮藏、支承、间隔或覆盖使用的器物，是室内空间的重要组成部分。

### 1.2 家具的分类

#### 按功能分类
```
家具类型
├── 坐具类    # 椅子/沙发/凳子
├── 卧具类    # 床/床垫
├── 桌具类    # 桌子/茶几
├── 柜类      # 衣柜/书柜/电视柜
├── 架类      # 书架/搁板
└── 床品类    # 床头柜/床尾凳
```

#### 按材质分类
| 类型 | 代表材料 | 特点 |
|-----|--------|------|
| 木质家具 | 实木/人造板 | 温润/耐用 |
| 金属家具 | 钢/铝/铁 | 坚固/现代 |
| 塑料家具 | PP/ABS | 轻便/便宜 |
| 玻璃家具 | 钢化玻璃 | 通透/时尚 |
| 石材家具 | 大理石/岩板 | 高级/耐用 |

#### 按风格分类
- 中式家具：明式/清式/新中式
- 西式家具：古典/新古典/现代
- 日式家具：传统/无印风
- 北欧家具：功能/简约

## 第二章：家具设计的基本原则

### 2.1 功能性原则

**首要原则**：满足使用功能

```
功能设计要点
├── 舒适性    # 符合人体工程学
├── 实用性    # 满足收纳/使用需求
├── 安全性    # 结构稳固/边缘处理
└── 便利性    # 使用方便/清洁简单
```

### 2.2 人体工程学标准

#### 2.2.1 座椅设计

| 参数 | 建议值 | 说明 |
|-----|-------|------|
| 坐高 | 40-45cm | 坐面到地面 |
| 坐深 | 45-55cm | 坐面前缘到靠背 |
| 坐宽 | ≥45cm | 扶手间宽度 |
| 靠背高 | 30-55cm | 支撑背部 |

#### 2.2.2 桌类设计

| 类型 | 桌高 | 桌面宽 | 桌面深 |
|-----|------|-------|-------|
| 餐桌 | 72-75cm | 60-80cm/人 | 60-75cm |
| 书桌 | 72-75cm | 120-160cm | 60-75cm |
| 茶几 | 40-50cm | 90-120cm | 45-60cm |
| 会议桌 | 72-75cm | 180-240cm | 90-120cm |

#### 2.2.3 床类设计

| 规格 | 长度 | 宽度 | 床高 |
|-----|------|-----|------|
| 单人床 | 200cm | 90/120cm | 45-55cm |
| 标准双人 | 200cm | 150cm | 45-55cm |
| 大双人 | 200cm | 180cm | 45-55cm |
| King Size | 200cm | 200cm | 45-55cm |

### 2.3 美观性原则

```
美观要素
├── 比例协调    # 整体与局部
├── 节奏韵律    # 重复/变化
├── 尺度适宜    # 适合空间
└── 风格统一    # 与室内协调
```

### 2.4 经济性原则

- **批量生产降低成本**
- **模块化设计**
- **材料利用率**
- **结构简化**

## 第三章：家具结构设计

### 3.1 传统榫卯结构

| 结构名称 | 特点 | 适用 |
|---------|------|------|
| 燕尾榫 | 牢固/抗拉 | 抽屉/面板 |
| 穿带榫 | 承重/平直 | 案面/台面 |
| 楔钉榫 | 可拆/牢固 | 圈椅/圆脚 |
| 抱肩榫 | 承重/稳定 | 桌腿/椅腿 |

### 3.2 现代连接方式

| 连接方式 | 优点 | 缺点 |
|---------|------|------|
| 螺丝连接 | 简单/可拆 | 不美观 |
| 三合一 | 美观/可拆 | 需预埋 |
| 槽口连接 | 美观/牢固 | 工艺复杂 |
| 粘接 | 简单 | 难拆 |

### 3.3 典型结构示例

#### 3.3.1 抽屉结构

```
抽屉组成
├── 抽屉帮    # 侧板+底板
├── 抽屉背   # 后板
├── 抽屉面   # 正面
├── 抽屉底   # 底板(5-8mm)
└── 导轨   # 滑道
```

**国家标准**：
- 抽屉深：≤50cm
- 底板厚：≥5mm
- 滑道承重：≥30kg

#### 3.3.2 柜体结构

```
标准柜体组成
├── 侧板     # 18mm
├── 顶底板   # 18mm
├── 层板     # 18mm
├── 背板     # 3-5mm
└── 脚      # 40-50mm
```

## 第四章：家具材料选择

### 4.1 木材

| 木材 | 属性 | 特点 | 适用 |
|-----|------|------|------|
| 橡木 | 硬木 | 纹美/耐腐 | 高端家具 |
| 桦木 | 硬木 | 硬度高/便宜 | 儿童家具 |
| 杉木 | 软木 | 轻/有香味 | 杉木家具 |
| 榆木 | 硬木 | 花纹美/耐用 | 中式家具 |
| 柚木 | 硬木 | 耐腐/贵 | 高端户外 |

### 4.2 人造板

| 板材 | 全称 | 特点 | 环保 |
|-----|------|------|------|
| 胶合板 | 多层板 | 防潮/强度高 | E1级 |
| 细木工板 | 大芯板 | 握钉力好 | E1级 |
| 刨花板 | 颗粒板 | 便宜/平整 | E1级 |
| 密度板 | 中纤板 | 可造型 | E1级 |
| OSB | 欧松板 | 强度高/防潮 | E0级 |

### 4.3 五金配件

| 类别 | 配件 | 作用 |
|-----|------|------|
| 连接件 | 三合一/螺丝 | 板件连接 |
| 导轨 | 滑轨/阻尼 | 抽屉/柜门 |
| 铰链 | 合页/阻尼 | 门板开合 |
| 脚轮 | 万向轮/定向轮 | 移动 |
| 拉手 | 把手/拉手 | 开启 |

## 第五章：家具风格与室内搭配

### 5.1 风格对应关系

| 室内风格 | 家具特点 | 材质 |
|---------|---------|------|
| 奶油风 | 圆润/布艺/浅色 | 布艺/浅木 |
| 北欧风 | 简约/功能/木腿 | 白橡/浅色 |
| 日式 | 低矮/原木/藤编 | 杉木/藤编 |
| 新中式 | 对称/雕刻/实木 | 红木/黑檀 |
| 意式 | 简约/皮质/品质 | 皮/金属 |
| 工业 | 复古/金属/皮质 | 铁/皮/砖 |

### 5.2 选购建议

1. **先定家具后装修**
2. **同一风格贯穿全屋**
3. **环保性：E1级以上**
4. **口碑品牌有保障**
5. **保存购买凭据**
