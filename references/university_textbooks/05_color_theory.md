## 第一章：色彩基础理论

### 1.1 色彩的构成

```
色彩三要素
├── 色相    # 色彩的相状（Hue）
├── 明度    # 明暗程度（Value）
└── 饱和度  # 鲜艳程度（Chroma）
```

### 1.2 孟塞尔色彩体系

| 属性 | 定义 | 表示 |
|-----|------|------|
| 色相 | 色彩的相状 | H 0-360 |
| 明度 | 黑白程度 | V 0-10 |
| 饱和度 | 鲜艳程度 | C 0-12 |

### 1.3 基本色相

| 色相 | 角度 | 心理感受 |
|-----|------|---------|
| 红色 | 0° | 热情/活力/危险 |
| 橙色 | 30° | 温暖/快乐/亲切 |
| 黄色 | 60° | 明亮/快乐/警示 |
| 黄绿色 | 90° | 新鲜/自然/年轻 |
| 绿色 | 120° | 自然/平静/安全 |
| 蓝绿色 | 150° | 冷静/专业/清凉 |
| 蓝色 | 180° | 冷静/科技/信赖 |
| 蓝紫色 | 210° | 神秘/高贵/优雅 |
| 紫色 | 240° | 神秘/浪漫/高贵 |
| 紫红色 | 270° | 热情/浪漫/性感 |

## 第二章：色彩心理效应

### 2.1 色彩情感与空间

| 色彩 | 正向情感 | 负向情感 | 适用空间 |
|------|---------|---------|---------|
| 白色 | 纯洁/明亮 | 冷漠 | 所有空间 |
| 黑色 | 高级/个性 | 压抑 | 背景/点缀 |
| 灰色 | 现代/精致 | 空虚 | 过渡色 |
| 米色 | 温暖/舒适 | 平淡 | 客厅/卧室 |
| 蓝色 | 冷静/放松 | 冷淡 | 书房/卧室 |
| 绿色 | 自然/舒适 | - | 客厅/儿童房 |
| 红色 | 热情/喜气 | 躁动 | 餐厅/点缀 |
| 橙色 | 温暖/活力 | 刺眼 | 餐厅/儿童 |

### 2.2 色彩与功能

```
色彩功能分区
├── 膨胀色    # 浅色/使空间显大
├── 收缩色    # 深色/使物体显小
├── 前进色    # 暖色/使距离变近
├── 后退色    # 冷色/使距离变远
├── 重色      # 深色/使物体显重
└── 轻色      # 浅色/使物体显轻
```

## 第三章：室内配色原则

### 3.1 60-30-10法则

这是最经典的室内配色法则：

```
配色比例
├── 60% 主色    # 墙面/天花板/大面积
├── 30% 辅助色  # 家具/窗帘/地毯
└── 10% 点缀色  # 配饰/抱枕/花卉
```

**配色示例（奶油风）**：
- 主色（60%）：奶白色墙面
- 辅助色（30%）：米灰色沙发
- 点缀色（10%）：浅粉色抱枕

### 3.2 配色方案

#### 3.2.1 同色系配色

```
特点：同一色相，不同明度和饱和度
优点：和谐/统一/容易搭配
示例：浅蓝 + 中蓝 + 深蓝
```

#### 3.2.2 邻近色配色

```
特点：色环上相邻的颜色（30°内）
优点：和谐中有变化
示例：蓝色 + 蓝绿色 + 绿色
```

#### 3.2.3 对比色配色

```
特点：色环上相对的颜色（180°）
优点：醒目/活泼
示例：蓝色 + 橙色
注意：控制比例，避免刺眼
```

#### 3.2.4 分裂互补配色

```
特点：主色 + 互补色两侧的颜色
优点：既对比又和谐
示例：蓝色 + 橙黄色 + 橙红色
```

### 3.3 不同空间的配色

| 空间 | 推荐色温 | 配色重点 |
|-----|---------|---------|
| 客厅 | 3000-4000K | 温馨/社交/明亮 |
| 卧室 | 2700-3000K | 放松/安静/温暖 |
| 厨房 | 4000-5000K | 清爽/干净/明亮 |
| 餐厅 | 3000-3500K | 食欲/温暖/舒适 |
| 书房 | 4000K | 专注/安静/护眼 |
| 卫生间 | 4000-5000K | 清爽/干净/明亮 |

## 第四章：色彩与材质

### 4.1 材质对色彩的影响

| 材质 | 色彩效果 | 适用风格 |
|-----|---------|---------|
| 实木 | 温润/自然 | 日式/北欧/中式 |
| 金属 | 冷硬/时尚 | 意式/工业 |
| 布艺 | 柔和/温暖 | 奶油/北欧 |
| 玻璃 | 通透/现代 | 现代/北欧 |
| 大理石 | 高档/冷艳 | 意式/欧式 |

### 4.2 色彩与光泽

- **高光泽**：浅色显得轻盈，深色显得厚重
- **低光泽**：柔和/温暖
- **哑光**：柔和/内敛

## 第六章：色彩与光照

### 6.1 光照对色彩的影响

| 光源 | 对色彩的影响 |
|-----|-----------|
| 自然光 | 最真实 |
| 白炽灯 | 偏暖/偏黄 |
| 日光灯 | 偏冷/偏蓝 |
| LED灯 | 取决于色温 |

### 6.2 不同色温的视觉效果

| 色温 | 视觉感受 | 适用 |
|-----|---------|------|
| 2700K | 温暖/黄 | 卧/餐厅 |
| 3000K | 柔和/暖白 | 客厅/卧室 |
| 4000K | 中性/亮白 | 书房/厨房 |
| 5000K | 清冷/亮 | 厨/卫/工作区 |
