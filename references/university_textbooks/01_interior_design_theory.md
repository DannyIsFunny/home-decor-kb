## 第一章：室内设计的定义与范畴

### 1.1 室内设计的概念

室内设计（Interior Design）是指根据建筑物的使用性质、所处环境和相应标准，运用物质技术手段和建筑美学原理，创造功能合理、舒适优美、满足人们物质和精神生活需要的室内环境。

### 1.2 室内设计的范畴

```
室内设计范畴
├── 空间设计     # 空间划分/组织/形态
├── 物理环境    # 采光/通风/保温
├── 装修构造    # 界面/材质/工艺
├── 家具陈设    # 家具/布艺/灯具
└── 色彩设计    # 配色/氛围
```

## 第二章：室内设计的程序与方法

### 2.1 设计流程（5阶段）

| 阶段 | 内容 | 产出 |
|-----|------|------|
| 1. 调研分析 | 了解需求/现场测量/资料收集 | 需求报告 |
| 2. 方案设计 | 概念方案/空间布局/风格定位 | 方案文本 |
| 3. 初步设计 | 平面布置/效果图/材料选型 | 施工图初稿 |
| 4. 施工图设计 | 详细图纸/节点大样/材料表 | 施工蓝图 |
| 5. 现场配合 | 工地指导/变更处理/验收 | 竣工项目 |

### 2.1.1 调研分析要点

- **业主需求**：功能/风格/预算/偏好
- **现场条件**：尺寸/朝向/管线/梁柱
- **规范要求**：防火/疏散/环保
- **相邻关系**：噪音/隐私/视线

### 2.2 设计方法

#### 2.2.1 空间组织方法

```
空间组织原则
├── 动静分区    # 活动区vs休息区
├── 洁污分离    # 厨房/卫生间vs客厅/卧室
├── 主次分明    # 核心空间vs辅助空间
└── 动线流畅   # 避免交叉/最短路径
```

#### 2.2.2 空间序列设计

**四阶段空间序列**：
1. **起始** - 入门/玄关（预告）
2. **过渡** - 走廊/转换（引导）
3. **高潮** - 客厅/餐厅（主体）
4. **尾声** - 卧室/书房（回味）

## 第三章：室内设计风格体系

### 3.1 主要风格分类

| 风格 | 时期 | 特点 |
|-----|------|------|
| 现代简约 | 20世纪至今 | 功能至上/简洁线条 |
| 北欧 | 20世纪 | 自然/功能/明亮 |
| 日式 | 传统/现代 | 自然/极简/禅意 |
| 新中式 | 现代 | 传统+现代/雅致 |
| 意式极简 | 现代 | 品质/奢华/简洁 |
| 工业 | 20世纪后期 | 粗犷/个性/复古 |
| 法式 | 古典/新古典 | 浪漫/对称/精细 |
| 美式 | 古典/乡村 | 舒适/自由/厚重 |

### 3.2 风格的确定因素

1. **建筑条件**：户型/层高/结构
2. **业主偏好**：生活方式/审美
3. **预算限制**：材料选择/工艺
4. **文化背景**：地域/民族/时代

## 第四章：人体工程学在室内设计中的应用

### 4.1 人体尺度数据（中国成年人）

| 项目 | P5 | P50 | P95 |
|-----|-----|-----|-----|
| 身高(mm) | 1600 | 1700 | 1800 |
| 眼高(mm) | 1480 | 1580 | 1680 |
| 坐高(mm) | 840 | 900 | 960 |
| 肩宽(mm) | 380 | 420 | 460 |

### 4.2 家具尺寸设计原则

```
家具设计原则
├── 坐着舒适    # 坐深50-60cm，坐高45-50cm
├── 站着方便    # 台面高80-85cm
├── 跪着不碰头  # 阁楼净高>50cm
├── 通行顺畅    # 通道宽>60cm
└躺着合适    # 床宽单人>90cm，双人>150cm
```

### 4.3 无障碍设计要求

- **轮椅回转空间**：直径≥150cm
- **门洞净宽**：≥80cm
- **扶手高度**：85-90cm
- **门槛高**：≤2cm

## 第五章：室内采光与照明设计

### 5.1 采光标准

| 房间 | 采光系数 | 窗地比 |
|-----|---------|--------|
| 客厅 | ≥1% | 1/7 |
| 卧室 | ≥1% | 1/7 |
| 厨房 | ≥1% | 1/7 |
| 卫生间 | ≥0.5% | 1/10 |
| 走廊 | ≥0.5% | 1/10 |

### 5.2 照明层次设计

**四层次照明理论**（Ching）：
1. **环境光** - 整体照明，30-50lux
2. **任务光** - 工作照明，300-500lux
3. **焦点光** - 展示照明，500-1000lux
4. **装饰光** - 氛围照明，100-200lux

### 5.3 色温选择

| 场景 | 色温 | 适用 |
|-----|------|------|
| 客厅 | 3000-4000K | 明亮温馨 |
| 卧室 | 2700-3000K | 温暖舒适 |
| 厨房 | 4000-5000K | 明亮清爽 |
| 阅读 | 4000K | 护眼 |

## 第六章：室内色彩设计

### 6.1 配色原则

#### 6.1.1 60-30-10法则（Ching）

- **60%** - 主色（墙面/大面积）
- **30%** - 辅助色（家具/窗帘）
- **10%** - 点缀色（配饰/抱枕）

#### 6.1.2 色彩情感

| 色彩 | 情感 | 适用空间 |
|-----|------|---------|
| 白色 | 纯洁/明亮 | 所有空间 |
| 米色 | 温暖/舒适 | 客厅/卧室 |
| 灰色 | 现代/精致 | 现代风格 |
| 木色 | 自然/温润 | 日式/北欧 |
| 黑色 | 个性/高级 | 意式/工业 |

### 6.2 色彩协调方法

1. **同色系**：同一色相不同明度
2. **邻近色**：色环相邻30°
3. **对比色**：色环相对180°
4. **分裂互补**：主色+互补的临近色

## 第七章：装修材料与构造

### 7.1 地面材料

| 材料 | 优点 | 缺点 | 适用 |
|-----|------|------|------|
| 实木地板 | 温润/环保 | 娇气/贵 | 卧室/客餐厅 |
| 复合地板 | 稳定/便宜 | 不环保 | 全屋 |
| 地砖 | 耐磨/防水 | 冷硬 | 厨卫/阳台 |
| 石材 | 大气/耐磨 | 贵/滑 | 客厅/大堂 |

### 7.2 墙面材料

| 材料 | 优点 | 缺点 | 适用 |
|-----|------|------|------|
| 乳胶漆 | 便宜/环保 | 单调 | 全屋 |
| 壁纸 | 温馨/花样 | 翘边 | 卧室/背景墙 |
| 硅藻泥 | 环保/肌理 | 贵 | 背景墙 |
| 木饰面 | 温润/品质 | 贵 | 背景墙/门 |

### 7.3 吊顶材料

| 材料 | 优点 | 缺点 | 适用 |
|-----|------|------|------|
| 石膏板 | 便宜/可造型 | 不防水 | 客厅/卧室 |
| 铝扣板 | 防水/易清洁 | 工业感 | 厨卫 |
| 蜂窝大板 | 大气/防水 | 贵 | 厨卫/大客厅 |

## 第八章：预算与成本控制

### 8.1 预算分配比例

**建议配比**：
- 硬装：50%
- 软装：30%
- 家电：20%

### 8.2 省钱策略

1. **隐蔽工程不省** - 水电/防水
2. **大件家具提前定** - 交期长
3. **旺季反季买** - 大促
4. **木工少做** - 工厂定制更便宜
5. **轻装修重装饰** - 软装改变风格
