# 《Space Planning Basics》- 空间规划基础原理

---

## 一、空间规划概论

空间规划（Space Planning）是室内设计的核心环节，它决定了空间的功能效率、流通路径和使用体验。一个再漂亮的室内设计方案，如果空间规划不当，也会成为居住者的长期噩梦——每天都在为"别扭的动线"、"不够用的收纳"、"找不到的东西"而烦恼。

空间规划的本质是对**人与空间**关系的系统性安排。它需要回答以下问题：
- 每个房间应该多大？
- 各房间之间应该是什么关系？
- 人和物在空间中如何移动？
- 私密空间和公共空间如何过渡？
- 阳光和通风如何分配？

### 2.3 家具与人体尺度配合

**餐桌与餐椅**：
- 标准餐桌高度：72-75cm
- 餐椅座高：44-46cm（桌面与椅座高差约28-30cm，人坐下后肘部自然下垂距桌面约10cm）
- 4人餐桌最小尺寸：长120cm×宽75cm
- 6人餐桌最小尺寸：长150cm×宽80cm
- 8人餐桌最小尺寸：长180cm×宽90cm
- 餐桌周围过道：至少60cm（方便入座和起身）

**沙发与茶几**：
- 沙发座高：40-45cm（低于床面和餐桌面）
- 沙发座深：48-55cm（亚洲人标准），70cm以上为"懒人沙发"
- 沙发靠背高度：70-85cm（低靠背55-65cm）
- 沙发座面到茶几台面高差：15-25cm（最佳视差）
- 茶几到沙发距离：35-45cm（腿能舒适伸入）
- 电视到沙发视距：电视英寸×2.5-3（cm）——55寸电视最佳观看距离约1.4-1.7m

**床与卧室**：
- 床垫厚度：15-30cm（舒适层），总高度（床架+床垫）45-55cm
- 床头柜高度：55-65cm（与床垫面齐平或略低5cm）
- 卧室过道（床两侧）：60cm（最低），90cm（舒适）
- 衣柜深度：55-60cm（挂长大衣需58cm以上）
- 衣柜内部挂衣杆高度：男性区域180cm，女性区域160cm
- 穿衣镜最小高度：120cm（全身镜需150cm高度）

**厨房人体工学**：
- 地柜台面高度（站立操作）：85-95cm
  - 快速判断公式：身高÷2 ± 5cm
  - 如果经常两人同时做饭，建议做高低台面（水槽区略高约5-10cm，保护腰部）
- 吊柜底部离台面距离：50-60cm
- 吊柜深度：30-35cm（超过35cm容易碰头）
- 操作台进深：60cm（标准）
- 操作台有效深度（扣除前方空间）：45cm
- 吸油烟机底部离灶台距离：65-75cm（侧吸可略低）
- 灶台与操作台高差：0（平齐）或操作台高于灶台3-5cm
- 冰箱开门角度内所需通道宽度：60cm（浅冰箱）、90cm（对开门冰箱）

## 三、空间规划基本流程

### 3.1 需求分析（Program）

空间规划的第一步是全面了解居住者的需求，包括：

**定量信息**：
- 家庭成员数量及年龄结构
- 各房间使用频率和时段
- 访客频率和留宿需求
- 宠物数量和类型
- 车辆数量（车库/车位需求）

**定性信息**：
- 生活方式（宅家型/社交型/户外型）
- 烹饪习惯（中餐为主/西餐为主/几乎不做饭）
- 工作需求（居家办公/视频会议/创作需求）
- 收纳偏好（展示型/隐藏型/分类型）
- 特殊需求（老年人/婴幼儿/残障人士/过敏体质）

### 3.2 功能分区与面积分配

住宅功能分区通常遵循以下原则：

**公共区（Shared Zone）**：客厅、餐厅、厨房、玄关
- 特点：承载家庭共同活动和社交功能
- 布局要求：与入口紧密连接、各公共空间之间视线或动线流通

**私密区（Private Zone）**：主卧、次卧、书房
- 特点：需要安静和私密性
- 布局要求：位于住宅深处、远离入口和公共区

**服务区（Service Zone）**：卫生间、洗衣房、储物间、设备间
- 特点：功能性为主
- 布局要求：靠近主要功能区但相对隐蔽

**经典面积配比（以100㎡三室两厅为例）**：

| 功能区 | 面积范围 | 占比 |
|--------|----------|------|
| 客厅 | 18-25㎡ | 18-25% |
| 餐厅 | 10-15㎡ | 10-15% |
| 主卧 | 14-20㎡ | 14-20% |
| 次卧 | 9-14㎡ | 9-14% |
| 书房 | 8-12㎡ | 8-12% |
| 厨房 | 6-10㎡ | 6-10% |
| 主卫 | 5-8㎡ | 5-8% |
| 公卫 | 3-5㎡ | 3-5% |
| 玄关 | 2-4㎡ | 2-4% |
| 过道 | 8-12㎡（含分摊） | 8-12% |

### 3.3 流线分析与气泡图

**气泡图（Bubble Diagram）**是空间规划最常用的初步分析工具：

```
步骤1：用圆形气泡表示每个功能区，气泡大小表示面积比例
步骤2：用线段表示功能区之间的流动关系
步骤3：标注流动的频率和重要性（用线段粗细或虚实表示）
步骤4：调整气泡位置，使高频流动的功能区尽量接近
```

**典型住宅的功能关系矩阵**：

| 功能区 | 应紧邻 | 应远离 | 可接受 |
|--------|--------|--------|--------|
| 客厅 | 餐厅、玄关、阳台 | 卧室、卫生间 | 厨房（开放式） |
| 餐厅 | 客厅、厨房 | 卧室、卫生间 | — |
| 厨房 | 餐厅、阳台（生活阳台） | 主卧 | 卫生间 |
| 主卧 | 主卫、衣帽间 | 厨房、公共卫生间 | 客厅 |
| 次卧 | 公卫 | 厨房 | 客厅 |
| 玄关 | 客厅、鞋柜 | 卧室 | — |
| 公卫 | 卧室、客厅 | 厨房 | 餐厅 |
| 洗衣间 | 卫生间、阳台 | 客厅、主卧 | — |

## 四、住宅各空间规划要点

### 4.1 玄关规划

玄关是进入住宅的第一个空间，承担着"过渡"和"整理"的双重功能。

**玄关的必备功能**：
1. 换鞋（换鞋凳或换鞋区）
2. 收纳鞋（鞋柜，至少容量为家庭成员每人4-5双鞋+季节性收纳）
3. 挂外套（挂衣钩或衣柜）
4. 临时置物（钥匙、信件、快递）
5. 仪容整理（穿衣镜）

**玄关尺寸标准**：
- 最小玄关（独立式）：宽90cm×深150cm
- 标准玄关（独立式）：宽120cm×深180-200cm
- 走廊式玄关（过道型）：宽120cm（双人错位通过），150cm（双向通过）
- 鞋柜深度：30-35cm（标准男鞋），可做翻斗式节省空间
- 换鞋凳高度：42-45cm

**玄关规划常见错误**：
- 玄关过窄导致无法转身或放不下鞋柜
- 没有穿衣镜，出门前无法整理仪容
- 鞋柜容量不足，鞋子堆在门口
- 玄关灯光过暗（仅用吸顶灯会在面部形成阴影）

### 4.2 客厅规划

客厅是住宅的核心空间，规划要点在于"多功能"和"舒适度"的平衡。

**客厅功能分析**：
- 核心功能：会客、休闲（看电视、阅读）
- 延伸功能：家庭聚会、儿童游戏、健身、办公、用餐（开放式空间）

**客厅家具布局原则**：
- 沙发摆放应形成"对话"格局——面对面或"L"形排列
- 茶几位置应让所有人伸手可及（不超过1.5m距离）
- 电视观看轴线应避免正对窗户（眩光问题）
- 主要通道（连接入口和其他房间）不应穿越沙发区域

**客厅面积与家具配置参考**：

| 客厅面积 | 沙发配置 | 茶几 | 其他 |
|----------|----------|------|------|
| 12-15㎡ | 两人位+单椅 | 小型方/圆茶几 | 小边几 |
| 15-20㎡ | 三人位+单椅/贵妃榻 | 中型茶几 | 边几、书柜 |
| 20-30㎡ | 三人位+贵妃榻+单椅 | 大型茶几+边几组合 | 书架、休闲椅 |
| 30㎡以上 | 大型组合沙发 | 双茶几 | 钢琴、健身区 |

### 4.3 厨房规划

厨房是住宅中使用频率最高、功能最复杂的空间之一。好的厨房规划可以让烹饪效率提升30%以上。

**厨房布局类型及适用条件**：

| 布局类型 | 适用条件 | 操作效率 | 最小尺寸 |
|----------|----------|----------|----------|
| 一字型 | 狭长空间，只能单面布置 | ★★☆ | 宽1.5m×长3m |
| 双排型 | 宽度足够的空间，两面布置 | ★★★ | 宽2.1m×长3m |
| L型 | 墙角空间，两面墙成L形 | ★★★ | 宽1.8m×长2.4m（两臂长） |
| U型 | 宽裕空间，三面墙布置 | ★★★★ | 宽2.4m×深1.5m以上 |
| 岛台型 | 超大空间或开放式厨房 | ★★★★ | 整体进深4m以上 |

**黄金工作三角**：灶台-水槽-冰箱三者构成厨房的"黄金三角"。三角总边长应在3.6-6米之间，三边之和过短会导致操作局促，过长会导致往返疲惫。

**灶台-水槽-冰箱的最优顺序**：
冰箱（取食材）→ 操作台（备菜）→ 灶台（烹饪）→ 备餐台（装盘）→ 餐桌
这一线性流程是最高效的厨房操作动线。

**操作台分区（从左到右）**：
未加工食材区 → 清洗区 → 切割备菜区 → 烹饪区 → 装盘区
每个区域长度不应少于60cm。

### 4.4 餐厅规划

**餐厅面积与家具关系**：

| 用餐人数 | 最小餐桌尺寸 | 所需空间（包含椅子和通道） |
|----------|--------------|--------------------------|
| 2人 | φ70-80cm圆或60×80cm方 | 2.0m×2.0m |
| 4人 | 80×120cm方/圆 | 2.5m×2.8m |
| 6人 | 90×150cm方 | 3.0m×3.2m |
| 8人 | 90×180cm方 | 3.2m×3.6m |

**餐椅后方最小通道**：
- 仅通过：60cm
- 有人入座时侧身通过：80cm
- 有人入座时正常通过：100cm

**餐桌与吊灯关系**：
- 吊灯底部距桌面：65-75cm
- 吊灯直径：餐桌宽度的1/3至1/2
- 多盏吊灯（如长餐桌）：灯具总长为餐桌长度的60-80%

### 4.5 卧室规划

**床位布局原则**：
- 床头靠实墙（实墙给人安全感，避免床头靠窗或床头背后是门）
- 床头两侧应有通道（至少60cm，方便上下床和整理床铺）
- 床不宜正对卧室门（隐私性）
- 床的长边避免正对卫生间门（潮湿和气味）
- 主卧床头宜朝向东或东南（符合传统文化，但实际应以建筑朝向为准）

**主卧最小功能配置**：
- 1.8m×2.0m双人床
- 床头柜×2（或1个床头柜+梳妆台）
- 衣柜或衣帽间入口
- 电视或阅读区（可选）
- 梳妆台（独立或与书桌合并）

### 4.6 卫生间规划

**卫生间三分离/四分离**：
- 二分离：淋浴/浴缸 + 马桶+洗手台（隔断）
- 三分离：洗手台独立出来，马桶和淋浴各独立
- 四分离：洗手台+马桶+淋浴+洗衣区/更衣区（常见于日式主卫）

**各功能区最小尺寸**：
- 马桶区（不含洗手台）：宽90cm×深140cm（含前方60cm站立空间）
- 洗手台区：宽70cm×深60cm
- 淋浴区：最小80×80cm（方形），最佳90×90cm
- 浴缸：最小1.5×0.7m（坐式），1.7×0.75m（标准）
- 洗衣机位：宽60cm×深65cm

**卫生间门方向**：
- 门不应直接面对马桶（视线隐私）
- 门不应直接面对卫生间内部的洗浴区域
- 如果只有一个卫生间，门不应正对餐桌或厨房灶台

## 五、全屋收纳规划

### 5.1 收纳规划的基本原则

**就近原则**：收纳空间应布置在使用地点附近，而不是集中在一个区域。厨房的调料应在灶台附近而非冰箱旁的储物柜；客厅的纸巾和遥控器应在茶几附近。

**分层原则**：根据使用频率分配收纳高度。
- 黄金高度（距地面60-150cm）：最常用物品，伸手可及
- 高位（距地面150-200cm）：季节性物品、大型收纳箱
- 低位（距地面30-60cm）：较重物品，儿童用品
- 地面层（距地面30cm以下）：大型物品、最重物品、行李箱

**分类原则**：同类物品集中收纳，不同类别有明显分隔。
- 食品类：大米、面条、调味料分别归类
- 衣物类：季节分类+类型分类（上装、下装、内衣、袜子）
- 工具类：清洁工具、工具箱、梯子分别放置

**容量原则**：收纳容器的容量应略大于实际需求（80-90%填满为最佳），留有取放物品的余地。

### 5.2 各空间收纳量参考

| 空间 | 收纳项目 | 参考容量 |
|------|----------|----------|
| 玄关 | 鞋、外套、包、雨具、钥匙信件、童车（可选） | 鞋柜深度30cm×层数8-10层；外套挂钩4-6个 |
| 客厅 | 客厅杂物（纸巾、遥控器）、书籍、展示品 | 电视柜深度40cm；展示架按需；地柜抽屉2-3组 |
| 餐厨 | 餐具、食材、厨具、小家电、调料、干货 | 地柜3-4组抽屉；吊柜2-3组；高柜（调味品+米面） |
| 卧室 | 衣物、被褥、行李箱、首饰、梳妆用品 | 衣柜按每人1.5-2.0m宽（挂衣区占60%，折叠区40%） |
| 卫生间 | 洗浴用品、毛巾、卫生用品、清洁工具、化妆品 | 镜柜深度12-15cm；浴室柜深度55-60cm |
| 阳台 | 清洁工具、拖把池、洗衣机、干衣机、绿植 | 按实际需求定制 |

## 六、光线与通风规划

### 6.1 自然采光原则

- 客厅和主卧应优先获得南向或东南向的自然采光
- 厨房应有独立采光，不应完全依赖人工照明
- 卫生间如无自然采光，必须配置足够的人工照明和换气系统
- 走廊和楼梯间应尽可能引入自然光（天窗、玻璃隔断）

### 6.2 通风原则

- 厨房必须配置抽油烟机，排风量≥15立方米/分钟
- 卫生间应配置换气扇，排风量≥10立方米/分钟
- 有窗户的卫生间，窗户应可开启且面积不小于地面的1/10
- 相邻空间的窗户应错开布置，避免形成通风"死角"
