# 🏠 Home Decor Knowledge Base (home-decor-kb)

专业装修知识库 - 室内设计与家具选配专家

## 简介

这是一个 OpenClaw Agent Skill，提供专业的装修知识和家具选配建议。

## 功能

- 🎨 装修风格咨询（奶油风/北欧/日式/新中式等）
- 🪑 家具选配建议
- 🔧 硬装/软装标准
- 💰 预算规划
- 🎨 色彩搭配
- 💡 灯光设计
- ⚠️ 装修避坑指南

## 安装

```bash
# 放到 agents skills 目录
cp -r home-decor-kb ~/.agents/skills/
```

## 使用

在对话中触发：
- "装修风格建议"
- "家具选配"
- "奶油风怎么样"
- "预算多少"
- "装修避坑"

## 知识库内容

- `knowledge_base/` - 专业知识内容
- `references/` - 权威书籍引用
- `scripts/` - 工具脚本
- `tests/` - 测试用例
